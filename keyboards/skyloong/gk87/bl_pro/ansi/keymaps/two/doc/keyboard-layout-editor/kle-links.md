## 1. `skyloong-gk87-two` — 层设计主图（改键位用）

**2×2 里放 3 把键盘**，同一列就是同一个物理键：

| 位置 | 层 | 入口 |
| --- | --- | --- |
| 左上 | ① ctrl | 短按**左空格** |
| 右上 | ② shift（含符号层） | 短按**右空格** |
| 左下 | ③ esc | **按住** Caps（原 Esc 位，单按仍是 Esc） |

**符号层**（快按 F 进入，敲完一个符号自动回上一层）已并入 ②：
**键帽上排 = shift 层输出，Bottom Legend = 符号层输出**；两层输出相同的键只留一份。
右下那一格原本是符号层那张图，合并后空着。

**空格**：ctrl / shift / 符号 层里，左右空格都是「切到 ctrl / shift 层」（绿色）。
esc 层是按住触发的，松开 Caps 自动回到进本层之前的层，所以空格保持普通按键。

- 🟧 橙 = 已有明确设计；🟩 绿 = 分裂空格（层入口）；🟫 深棕 = 右手食指常驻位
- 本地文件：`keymaps/skyloong-gk87-two.json`（**这份是唯一的源**，改键位直接在它里面改）
- 合并脚本：`tmp/merge-symbol-into-shift.py`
